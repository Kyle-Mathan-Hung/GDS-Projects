# Kyle Hung
Geospatial Data Science Student, University of Waterloo

## Portfolio
This repository contains a selection of spatial analysis, network modeling, and cartography projects. Each folder includes the methodology, tools used, and final map layouts.

### 1. Region of Waterloo Fire Station Network Analysis
Evaluated emergency response times using service area and location-allocation analysis to recommend optimal new station placements, reducing system-wide average response times by 20%.
[View Project](./01-fire-station-network-analysis)

### 2. Multi-Criteria Site Suitability for Small-Scale Wind Farms
Identified regulation-compliant wind farm locations in the Niagara Region using weighted overlay and raster analysis, identifying two viable sites meeting all provincial safety and spacing guidelines.
[View Project](./02-wind-farm-suitability)

### 3. City of Kitchener Building Permit Geocoding & Spatial Analysis
Geocoded 26,000+ building permits with a 94% match rate to visualize 23 years of urban expansion and identify construction hotspots for infrastructure planning.
[View Project](./03-building-permit-geocoding)

### 4. Motor Vehicle Collision Hotspot Analysis
Analyzed 8 years of collision data using 1 km² hexagonal tessellation and spatial joins to identify persistent high-risk zones, highlighting the downtown core and major arterial interchanges.
[View Project](./04-collision-hotspot-analysis)

### 5. NBA Shot Efficiency & Spatial Comparison
Used ArcGIS Pro tessellation and Python to visualize and compare spatial shooting efficiency, analyzing performance differentials against team averages and the spatial shift in shot selection across eras.
[View Project](./05-nba-shot-chart-analysis)
